Trike is a game studio that fits in a sentence.

You describe the game. A world appears and keeps running. You steer it in chat or in code. Collaborators — direction, structure, build, critique, taste — work the same project you do. When it feels expensive, you publish a URL. The repo stays yours.

Chat, code, or live controls. Edits show up in the world that’s already going. No restart. No lost place.

04

A crew builds with you

Not one chatbot with a hard hat. Direction, structure, implementation, critique, taste — plus people whose job is to polish, break, and doubt the work.

05

We’re building for AA feel, not a jam-weekend sprite. If a stranger can tell it was generated, we failed.

The bar

If it looks generated, we failed.

We’re not shipping a toy that demos well in a GIF. The point is games that feel directed — the kind you’d actually send to a friend. Deterministic replays. Edits that don’t blow up the run. Taste with a veto.

  • Sentence → running game

    The preview is playable. That is the product, not a trailer.

  • The run survives the edit

    Ninety live swaps on an early spike. Place in the world held. About a second, worst case.

  • A crew, not a chatbot

    Jobs, taste, and the right to send work back. Your tools get those jobs too.

  • The git is yours

    Export. Commit. Leave. Come back. Agents don’t clobber the lines you wrote.
