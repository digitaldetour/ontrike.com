# Trike brand for ontrike.com

Product: **Trike** — an AI-native game IDE. Describe a game, watch it materialise in a live running preview, iterate conversationally or in code, ship it to a URL.

- Trike — the product people see
- Amber — the engine
- Trike Studio — the editor
- play.ontrike.com — the player (later)

Domain: **ontrike.com** (Cloudflare).

## Palette (Resin)

Surfaces are stone; all warmth lives in amber.

- Bedrock `#131212`
- Sediment `#1B1A19`
- Shale `#242220`
- Recess `#0E0D0D`
- Bone `#F2EFE9` (primary text)
- Dust `#A8A399` (secondary text)
- Amber glow `#F5A524` (one moment per view)
- Amber deep `#B96E12`
- Tile white `#F5F4EF` (mark light)
- Obsidian `#08090A` (mark dark)
- Stone `#D2B488`

Fonts (ideal): Gambarino (display), General Sans (UI), JetBrains Mono (mono). Fallbacks OK for v1: Georgia / system-ui / ui-monospace.

Geometry: chunky rounded-square (radius ~10–12px). Never sharp. Pill only for one control type.

Depth: ink line + strata steps, not heavy shadows. Amber is light, not paint — one solid amber primary CTA; selections use tint.
